# Workflow: Resilient & High-ROI Testing (`resilient-testing-workflow`)

Skill này hướng dẫn phương pháp thiết kế và lập trình các bộ kiểm thử tự động (Unit, Contract, State Machine, Component) sao cho **tập trung tối đa vào các rủi ro sống còn (High-ROI)**, **ngăn chặn AI over-engineering / viết test sai mục đích** và **hạn chế tối đa việc test bị gãy hoặc phải sửa lại khi tái cấu trúc code (Anti-Fragile & Minimal Maintenance)**.
